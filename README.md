# Week 1 Flutter Internship Project

## Project Overview

This project is a basic Flutter application developed for the Week 1 Flutter Frontend Development Internship task. It demonstrates screen design, navigation, forms, and basic user interactions.

## Screens

1. **Splash Screen** — Introduction screen with a Get Started button.
2. **Login Screen** — Email and password fields with basic form validation.
3. **Home Screen** — Welcome message and navigation to Profile and Settings.
4. **Profile Screen** — Displays sample user information.
5. **Edit Profile Screen** — Allows editing sample name and email fields.
6. **Settings Screen** — Contains a notification preference switch.

## Technologies

* Flutter
* Dart
* Material Design widgets

## Project Structure

* `lib/main.dart` — Contains the application entry point, UI screens, and navigation.
* `pubspec.yaml` — Contains project metadata and dependencies.
* `android/`, `web/`, and other platform folders — Platform-specific project files generated by Flutter.

## How to Run

1. Install Flutter and configure the development environment.
2. Open a terminal in the project root.
3. Run `flutter pub get`.
4. Run `flutter run -d chrome`.

## Limitations

This is a front-end demonstration. Login is not connected to a real authentication service, and profile changes are not permanently stored.



# Week 2 – TaskFlow: Task Management Application

## Project Overview

TaskFlow is a Flutter-based task management application designed to help users organize, track, and manage their daily activities through a clean and user-friendly interface.

## Features Implemented

* **Task Creation:** Add new tasks with titles, descriptions, and categories.
* **Task Editing:** Update existing task details.
* **Task Deletion:** Remove tasks when they are no longer required.
* **Task Completion:** Mark tasks as completed or pending.
* **Search Functionality:** Search tasks using keywords.
* **Category Filtering:** Filter tasks based on categories.
* **Local Data Persistence:** Store tasks using SharedPreferences so they remain available after restarting the application.
* **API Integration:** Fetch sample tasks from the JSONPlaceholder API.
* **Dashboard:** Display task statistics, progress, and task information.
* **Responsive UI:** Implement a modern interface using Flutter widgets and styling.

## Technologies Used

* Flutter
* Dart
* SharedPreferences
* HTTP Package
* JSONPlaceholder REST API

## 6. Debugging and Bug Identification

The application was manually tested to identify functional issues.

### Identified Issue: Empty Task Title Validation

**Problem:**

When users attempted to create a task without entering a title, the application rejected the submission but initially did not display clear validation feedback.

**Expected Behaviour:**

The application should display a validation message when the task title is empty.

**Fix Implemented:**

Added form validation using Flutter's TextFormField validator.

**Validation Message:**

"Please enter a task title"

**Result:**

The validation message was manually verified in the application. Empty and whitespace-only titles are rejected.
